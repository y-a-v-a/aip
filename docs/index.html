AIP Recipe Generator

A small private web app that writes lunch, dinner and dessert recipes using only the ingredients on your elimination-diet list, keeps every recipe it makes, and lets a single admin decide who gets in.

User guide

Signing in with your link, making recipes, saved recipes, the ingredient list, and what to do when something goes wrong.

Admin guide

Becoming the admin, inviting people by phone or email, sending login links, and taking access away again.

Developer guide

Architecture, auth internals, data files, configuration, local Docker, the Playwright suite and deployment.

At a glance

QuestionAnswer
Who can use it?Only people the admin has invited, by phone number or email.
How do people sign in?With a personal one-time link (then they stay signed in on that device for a year), or with phone/email + PIN if the admin gave them one.
Where is data kept?Plain files in data/ on the server — no database.
What does it cost?Each generated recipe is one paid OpenRouter API call (a few cents); every call is logged with its cost.
What is it built with?Plain PHP 8 and cURL. No framework, no Composer, no JavaScript build.
These pages are plain HTML in the repository’s docs/ folder — open them straight from disk, no server needed.
